# Arduino — Tutorials and Projects

This repository contains cool Arduino tutorials and projects, made for learning purposes.

Each project has its own folder, with the Arduino sketch (`.ino`) and a `README.md` file describing the components, wiring and how it works.

## Projects

- [telecomanda_ir](Ir_remote_cloner/) — learning IR remote that stores the command in a 24LC08B EEPROM

## Note

The code and schematics are provided as learning examples. Always check your components' pinouts in their datasheets before wiring.
